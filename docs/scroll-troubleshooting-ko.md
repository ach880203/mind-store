# 스크롤 잠김 트러블슈팅

## 1. 문제 상황

- 사용자 페이지에서 내용이 화면보다 길어도 스크롤이 전혀 되지 않았다.
- 특히 홈 화면에서 마음일기 모달을 연 뒤 다른 페이지로 이동한 다음부터 전체 페이지 스크롤이 막히는 현상이 나타났다.

## 2. 처음 의심했던 부분

- 전역 CSS에서 `html`, `body`, `#root`에 스크롤바를 숨기는 코드가 있어서 이것이 원인처럼 보였다.
- 하지만 해당 코드는 스크롤바 모양만 숨길 뿐, 실제 스크롤 자체를 막는 설정은 아니었다.
- 따라서 문제를 단순 CSS가 아니라, 런타임에서 `body` 스타일을 직접 바꾸는 코드로 좁혀서 확인했다.

## 3. 실제 원인

원인은 홈 화면 모달 제어 코드였다.

- 홈 화면에서 모달이 열리면 `document.body.style.overflow = "hidden"`으로 배경 스크롤을 막고 있었다.
- 그런데 사용자가 모달이 열린 상태에서 다른 페이지로 이동하거나 컴포넌트가 언마운트되면, `body`의 `overflow` 값을 복구하는 정리 코드가 없었다.
- 그 결과 브라우저는 계속 `overflow: hidden` 상태를 유지했고, 이후 페이지 전체가 스크롤되지 않았다.

정리하면 이 문제는 "모달 오픈 시 전역 스크롤 잠금은 걸었지만, 페이지 이탈 시 잠금 해제를 보장하지 않은 것"이 핵심 원인이었다.

## 4. 문제 코드의 성격

문제는 특정 화면 내부 상태를 제어하는 코드가 `body`라는 전역 DOM에 직접 영향을 준다는 점이다.

- 컴포넌트 상태는 사라졌는데
- 전역 DOM 스타일은 그대로 남아 있었고
- 그 결과 다른 페이지까지 영향 범위가 번졌다

이런 종류의 버그는 UI는 한 화면에서 시작되지만, 실제 장애는 애플리케이션 전체에서 보이기 때문에 포트폴리오에서 설명하기 좋은 사례다.

## 5. 해결 방법

해결은 단순하지만 중요했다.

- 모달 상태가 바뀔 때마다 기존 `body.style.overflow` 값을 먼저 저장한다.
- 모달이 열리면 `hidden`을 적용한다.
- 이 이펙트가 다시 실행되거나 컴포넌트가 언마운트될 때 이전 값을 복구한다.

즉, "전역 상태를 건드렸으면 반드시 cleanup으로 원복한다"는 원칙으로 해결했다.

## 6. 적용 코드

적용 위치: `src/pages/Home.jsx`

```jsx
useEffect(() => {
  const previousOverflow = document.body.style.overflow;

  document.body.style.overflow = openDiary ? "hidden" : "";

  // 전역 body를 건드린 값은 이 화면이 사라질 때 복구해야 다른 페이지까지 영향이 번지지 않습니다.
  return () => {
    document.body.style.overflow = previousOverflow;
  };
}, [openDiary]);
```

## 7. 결과

- 홈 화면에서 모달을 열고 닫아도 스크롤이 정상 동작한다.
- 모달을 연 상태에서 다른 페이지로 이동해도 스크롤 잠김이 남지 않는다.
- 전역 스크롤 버그가 페이지 전환 이후까지 이어지던 문제가 사라졌다.

## 8. 포트폴리오에 이렇게 적기 좋음

### 문제 정의

"모달 오픈 후 다른 페이지로 이동하면 전체 페이지 스크롤이 잠기는 전역 UI 버그가 있었다."

### 원인 분석

"모달 배경 스크롤을 막기 위해 `body overflow`를 직접 제어했지만, 컴포넌트 언마운트 시 원복 cleanup이 없어 전역 스타일이 누적되었다."

### 해결

"React `useEffect` cleanup을 사용해 기존 `body overflow` 값을 저장하고, 모달 상태 변경 및 언마운트 시 안전하게 복구하도록 수정했다."

### 배운 점

"컴포넌트 내부 기능이라도 `body`, `window`, `document` 같은 전역 객체를 건드릴 때는 반드시 정리 로직까지 같이 설계해야 한다."

## 9. 한 줄 요약

이 이슈는 CSS 문제가 아니라, 모달이 전역 `body` 스크롤 상태를 바꾼 뒤 되돌리지 않아 발생한 전역 상태 누수 문제였다.
