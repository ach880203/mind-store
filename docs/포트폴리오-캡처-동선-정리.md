# 포트폴리오 캡처 동선 정리

작성일: 2026-03-26

## 변경 목표

- 포트폴리오 제출이나 발표 자료에 넣을 화면을 어떤 순서로 캡처하면 좋은지 정리한다.
- 프로젝트를 처음 보는 사람도 흐름을 빠르게 이해할 수 있도록 대표 동선을 정리한다.

## 핵심 변경 요약

- 메인 화면은 현재 분위기를 유지한 채 설득력만 보강한 상태이므로 첫 화면 캡처용으로 적합하다.
- 이후에는 사용자 흐름과 관리자 흐름이 끊기지 않게 보이도록 순서를 잡는 것이 중요하다.
- 한 번에 모든 화면을 넣기보다, 역할이 분명한 장면만 고르는 것이 더 좋다.

## 캡처 우선순위

### 1. 메인 화면

- 목적: 프로젝트 분위기와 주제를 한 장으로 보여 주기
- 포인트:
  - "오늘 마음은 어땠나요?" 문구가 잘 보이게
  - 보조 설명 문구가 같이 보이게
  - 버튼 위치가 중앙에 정리된 상태로 캡처

### 2. 로그인 또는 회원가입 화면

- 목적: 사용자 진입 흐름을 보여 주기
- 포인트:
  - 입력창과 버튼이 한눈에 보이게
  - 데모 계정 안내가 함께 보이면 포트폴리오 설명이 쉬워짐

### 3. 상담 예약 화면

- 목적: 서비스가 단순 소개 페이지가 아니라 실제 상호작용 흐름이 있다는 점을 보여 주기
- 포인트:
  - 상담 상품 카드
  - 날짜/시간 선택
  - 예약 완료 화면 중 하나 선택

### 4. 상품 주문 화면

- 목적: 주문 흐름과 상품 상태 반영을 보여 주기
- 포인트:
  - 상품 카드 목록
  - 재고, 상태, 주문 버튼이 같이 보이게
  - 가능하면 주문 후 안내 문구까지 보이게

### 5. 마이페이지 화면

- 목적: 예약/주문/일기 기록이 연결된 구조를 보여 주기
- 포인트:
  - 상단 요약 카드
  - 예약 내역 또는 주문 내역 한 탭
  - 기록이 실제로 쌓여 보이는 상태

### 6. 관리자 화면

- 목적: 사용자 화면만 만든 프로젝트가 아니라는 점을 보여 주기
- 포인트:
  - 대시보드 또는 예약 관리 화면
  - 표나 상태값이 보이는 화면이 더 좋음

## 추천 캡처 순서

1. 메인 화면
2. 로그인 화면
3. 상담 예약 화면
4. 상품 화면
5. 마이페이지 화면
6. 관리자 화면

## 발표용 설명 포인트

### 메인 화면에서 말할 것

- 감정일기와 상담 예약, 상품, 마이페이지까지 이어지는 프로젝트라는 점
- 첫 프로젝트지만 사용자 흐름을 한 프로젝트 안에 묶어 보려 했다는 점

### 마이페이지 화면에서 말할 것

- 단순히 페이지를 여러 개 만든 것이 아니라, 예약과 주문 결과가 다시 확인되도록 연결했다는 점

### 관리자 화면에서 말할 것

- 사용자 화면과 관리자 화면을 분리했고, 권한 보호도 추가했다는 점

## 캡처 전 체크리스트

- 한글 깨짐이 없는지 확인
- 로그인 상태가 의도한 계정으로 되어 있는지 확인
- 마이페이지에 보여 줄 데이터가 충분한지 확인
- 관리자 화면이 관리자 계정으로 열려 있는지 확인
- 버튼, 제목, 상태값이 잘리지 않는 해상도인지 확인
- 너무 많은 정보를 한 화면에 넣지 않았는지 확인

## 최종 정리

- 메인 화면은 현재 느낌을 유지하는 것이 중요하므로 과하게 바꾸지 않는다.
- 대신 설명력 있는 문구와 실제 흐름이 이어지는 장면을 함께 보여 주는 방식으로 포트폴리오 완성도를 높인다.
